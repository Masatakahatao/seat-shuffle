# Seat Shuffle

焼きなまし法（Simulated Annealing）を使い、過去に同じ班になった回数や男女比を考慮して席・班を決めるブラウザアプリです。

## 主な機能

- 参加人数と班数を指定した班分け
- 欠席者を除外した席替え
- 過去に同じ班になった組み合わせの偏りを軽減
- 直前と同じ班番号・同じメンバーになることを抑制
- 実現可能な範囲で男女の偏りや孤立を抑制
- 遭遇回数を確認できるヒートマップ
- 結果の手動編集とクリップボードへのコピー
- CSV形式でのエクスポート・インポート
- ブラウザへの設定・履歴の自動保存

## 使い方

1. 全体の人数、班数、男性プレイヤーの番号を入力します。
2. 「運用を開始する」を押します。
3. 必要に応じて欠席者番号を入力します。
4. 「席替えを実行する」を押します。
5. 結果を編集、コピー、またはCSVで保存します。

番号は `1-20` のような範囲、または `1, 3, 5` のようなカンマ・空白区切りで入力できます。

## ローカルでの起動

このアプリはJavaScript Modulesを使用しているため、`index.html` を直接開かず、ローカルサーバー経由で起動してください。

### VS Code Live Server

1. VS Codeでこのリポジトリを開きます。
2. 拡張機能「Live Server」（Ritwick Dey）をインストールします。
3. `index.html` を右クリックします。
4. 「Open with Live Server」を選択します。

通常は `http://127.0.0.1:5500/index.html` で開きます。VS Code右下の「Go Live」から起動することもできます。

### Python

リポジトリのルートで次を実行します。

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。終了するときはターミナルで `Ctrl+C` を押します。

## GitHub Pagesでの公開

1. 変更をGitHubの `main` ブランチへ反映します。
2. GitHubリポジトリの「Settings」→「Pages」を開きます。
3. 「Build and deployment」のSourceで「Deploy from a branch」を選択します。
4. Branchに `main`、フォルダーに `/ (root)` を指定して保存します。

公開処理が完了すると、次のURLから利用できます。

`https://masatakahatao.github.io/seat-shuffle/`

## データの保存

設定、遭遇履歴、直前の結果はブラウザのLocal Storageに保存されます。同じ端末・同じブラウザ・同じURLでアクセスした場合に復元されます。

「全データをリセット」を実行すると、保存された設定と履歴は削除されます。削除後は復元できません。CSVには現在の班分けだけが出力され、累積履歴全体のバックアップにはならない点に注意してください。

## CSV

エクスポートされるCSVは、班番号とメンバー番号を保持します。同じ画面のCSVインポートから直前の班分けとして読み込み、遭遇履歴を引き継げます。

インポート時の人数・班数・男女設定には、画面上の基本設定が使用されます。CSVの班数が設定と異なる場合や、範囲外・重複した番号がある場合は読み込まれません。

## 対応環境

最新版のChrome、Edge、Firefox、Safariを推奨します。クリップボード機能は、ブラウザの権限設定によって利用できない場合があります。

## 技術構成

- HTML / CSS
- JavaScript（ES Modules）
- Local Storage
- Simulated Annealing

ビルド処理や外部ライブラリは使用していません。
